# 내 사업 세컨드 브레인 템플릿

바이브코딩 특별반 실습용 폴더 템플릿입니다. 내 사업에 대해 AI가 알아야 할 것을 한 곳에 모아 두고, 주차별 결과물(랜딩·콘텐츠·자동발행·퍼널)을 정해진 자리에 쌓아 갑니다.

## 받는 방법

**방법 1 — 깃허브 계정이 있으면 (추천)**
이 페이지 위쪽 초록색 **Use this template → Create a new repository** 를 누르고, 저장소를 **Private** 으로 만듭니다. 내 사업 정보가 들어가므로 공개로 두지 않습니다.

**방법 2 — 그냥 파일로 받기**
초록색 **Code → Download ZIP** 을 눌러 받은 뒤 압축을 풉니다.

받은 뒤 `내사업` 폴더를 ChatGPT 워크 앱(또는 Claude) 프로젝트에 연결하면 됩니다.

## 시작 순서

1. `내사업/폴더_안내.md` 를 읽고 폴더 구조를 확인합니다.
2. `내사업/내사업_세컨드브레인.md` 의 1~2번 섹션부터 채웁니다.
3. 사진·후기·기존 링크는 `내사업/_자료/` 에 넣습니다.
4. 토큰·키가 필요해지면 `내사업/_설정/.env.예시` 를 복사해 `.env` 로 이름을 바꾸고 값을 채웁니다.

> `.env` 는 절대 깃허브·채팅에 올리지 않습니다. 이 템플릿의 `.gitignore` 가 막아 두었지만, 직접 업로드할 때도 빼고 올리세요.
